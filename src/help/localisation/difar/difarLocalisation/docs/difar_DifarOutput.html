DIFAR Localisation

Output from the DIFAR System

Before PAMGuard version 2.03, DIFAR results were stored in the binary store, with the PAMGuard database optionally used for convenience.

The database stores one row for each DIFAR clip, in a format that can be read easily with a database management system (e.g. SQLite). The database is not suited to storing the audio of each DIFAR clip.

The binary store contains the audio of each DIFAR clip, so that the operator can review the data in Viewer mode. DIFAR binary files can be read in MATLAB with pgmatlab, in R with PamBinaries, and in Python with pypamguard.

Triangulations

Before PAMGuard version 2.03, triangulations were stored in the binary files. From version 2.03 they are stored only in the database, in two tables named after the module. For a module named "DIFAR Localisation" the tables are:

DIFAR Localisation Crossings: one row for each triangulation, containing its time, end time, number of DIFAR clips, location (Latitude, Longitude), errors in metres (XError, YError), how its DIFAR clips were chosen (MatchChoice: AUTO, OPERATOR or LEGACY), and its quality (CrossingAngle, OnBuoy).

DIFAR Localisation Crossings Children: one row for each DIFAR clip in each triangulation, linking the triangulation to the UID of the DIFAR clip. The time, sonobuoy, bearings and sonobuoy location of each DIFAR clip are stored in the row of the DIFAR clip itself, which is the only copy of any value derived from the sonobuoy. These values are updated after sonobuoys are edited.

The table names use the word "Crossings", the module's internal name for triangulations.

The source code includes an SQL query, src/difar/crossings/crossing_clips.sql, that joins the three tables into one row for each DIFAR clip in each triangulation. It can be run with sqlite3 to produce a CSV file.

DIFAR binary files, version 3

From PAMGuard version 2.03, DIFAR binary files are written at version 3. Triangulations are no longer stored within the DIFAR clips, but in the database tables described above. Older files can be read in Viewer mode, but not changed until the dataset has been upgraded. Reading version 3 files in MATLAB requires a release of pgmatlab that supports them.
